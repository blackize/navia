# NAVIA -- AI CAREER NAVIGATOR

## PRODUCT SPEC (HOW IT LOOKS & WORKS)

Version: 1.0

------------------------------------------------------------------------

# 1. PRODUCT EXPERIENCE PRINCIPLE

NAVIA is a guided system, not a browsing system.

Users must always feel:

> "The app tells me what to do next"

NOT:

- "I need to choose from many options"

------------------------------------------------------------------------

# 2. CORE UX FLOW

## Entry Flow:

1.  App Open
2.  Onboarding (AI questionnaire)
3.  AI Career Recommendation
4.  Home (personalized)
5.  Career Path
6.  Lesson Player
7.  Progress Loop

------------------------------------------------------------------------

# 3. INFORMATION ARCHITECTURE

## TAB BAR

- Home
- Explore
- Search
- Profile

------------------------------------------------------------------------

# 4. HOME SCREEN (MOST IMPORTANT SCREEN)

## RULE:

Home must show ONLY ONE PRIMARY PATH.

------------------------------------------------------------------------

## SECTIONS:

### 1. Continue Learning (highest priority)

- last watched lesson
- progress bar
- resume button

------------------------------------------------------------------------

### 2. Your AI Career Path (PRIMARY)

- single recommended path
- progress %
- CTA: Continue

------------------------------------------------------------------------

### 3. Recommended Alternatives

- max 2--3 paths only
- lower visual priority

------------------------------------------------------------------------

### 4. Explore Paths (secondary entry)

- grid of all paths

------------------------------------------------------------------------

# 5. ONBOARDING FLOW (CRITICAL UX)

## GOAL:

Reduce time-to-first-lesson \< 60 seconds

------------------------------------------------------------------------

### STEP 1: INTEREST

- Development
- Data / AI
- Design
- Security
- Testing
- Management

------------------------------------------------------------------------

### STEP 2: EXPERIENCE

- Beginner
- Basic knowledge
- Working in IT

------------------------------------------------------------------------

### STEP 3: GOAL

- Change career
- Get first job
- Increase income

------------------------------------------------------------------------

### STEP 4: TIME

- 15 min/day
- 30 min/day
- 1 hour/day
- 2+ hours/day

------------------------------------------------------------------------

## OUTPUT SCREEN

### "Your AI Career Plan"

System returns:

- 1 Primary Career Path (highlighted)
- 2 Alternative Paths

CTA: Start Learning

------------------------------------------------------------------------

# 6. CAREER PATH SCREEN

Each path includes:

- Title
- Outcome ("Become Frontend Developer")
- Description
- Modules list
- Progress %
- Estimated duration
- Start/Continue button

------------------------------------------------------------------------

# 7. MODULE SCREEN (LOGICAL GROUPING)

Each module contains:

- title
- list of lessons
- completion status

------------------------------------------------------------------------

# 8. LESSON SCREEN (VIDEO EXPERIENCE)

## CORE PRINCIPLE:

Video-first experience, minimal UI.

------------------------------------------------------------------------

## FEATURES:

- HLS streaming
- playback speed (1x--2x)
- autoplay next lesson
- picture-in-picture
- resume playback

------------------------------------------------------------------------

## UI ELEMENTS:

- lesson title
- module name
- progress indicator
- next lesson suggestion

------------------------------------------------------------------------

# 9. EXPLORE SCREEN

Displays ONLY Career Paths.

Each card contains:

- title
- outcome
- difficulty
- duration

NO courses, NO LMS structure visible.

------------------------------------------------------------------------

# 10. SEARCH

Search across:

- career paths
- modules
- lessons

------------------------------------------------------------------------

# 11. PROGRESS SYSTEM

Tracks:

- completed lessons
- progress per path
- last watched lesson
- continue pointer

------------------------------------------------------------------------

# 12. SUBSCRIPTION EXPERIENCE

Single plan:

> NAVIA All Access

User gets:

- all career paths
- all content
- future updates

------------------------------------------------------------------------

# 13. NON-NEGOTIABLE UX RULES

- Always show 1 recommended path first
- Never show full catalog on first screen
- Never expose LMS structure
- System must feel AI-guided

------------------------------------------------------------------------

END OF PRODUCT SPEC
